# LiveProteinBench — GPT-6 Luna answers and explanations

**1,736 questions · 1,134 correct · 65.32% accuracy.**

This collection contains every saved visible answer and explanation from the reviewed sequence-only evaluation, including the one unparsed answer counted incorrect. The model used high reasoning effort and a 32,768-token output limit. The complete dataset has 1,797 questions; the 61 excluded questions are not included.

Each task page contains its shared system instruction once, followed by every complete question-specific input and visible model response. These pages show Luna’s visible response, not a transcript of its internal reasoning. Readable reasoning summaries were not requested. The encrypted internal state and private API metadata are excluded. Answer correctness is scored; explanation correctness is not independently assessed.
