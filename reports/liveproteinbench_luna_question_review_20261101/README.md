# LiveProteinBench: every question and Luna’s review

All **1,736 admitted questions** are linked below with their complete sequence, ordered choices, author key, full visible Luna review, and source qualifications. The 61 previously excluded source questions remain excluded.

Luna produced **1,735 format-valid reviews and one invalid citation record**. Among the valid reviews, expected-answer support was **1,690 supported, 31 contradicted, and 14 uncertain**; answerability was **442 reasoning-supported, 1,292 lookup-dependent, and one uncertain**. **The 31 contradicted judgments are AI review flags, not 31 confirmed key errors.** Project source notes preserve disagreements and identify errors in some reviewer arguments.

**How to read the two labels:** “expected-answer support” assesses the author key against reviewer-only source evidence; “reasoning / lookup” assesses what can be inferred from the original question. A database match is not proof of reasoning-based answerability. “Uncertain” displays the saved `cannot_determine` label; “lookup-dependent” displays `lookup_or_memorization_dependent`.

**Limits:** This is AI review, not independent expert adjudication. Original keys and benchmark scores are unchanged. No Qwen question reviews are available, so this is not a cross-model comparison. The single **† invalid-citation** row retains Luna’s actual saved labels and full review, but is excluded from the counts above.
