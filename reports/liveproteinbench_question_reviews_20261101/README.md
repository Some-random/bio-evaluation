# LiveProteinBench: Luna and Qwen question reviews

All **1,736 frozen admitted questions** remain visible below, including invalid or missing reviews. Each page contains the complete sequence, ordered choices, author key, both saved visible reviews, cited source excerpts, and existing project source notes. **Both reviewers saw the author key plus source evidence: these counts describe review judgments, not benchmark-solving accuracy.**

The **61 earlier source-question exclusions** remain outside this cohort. They are separate from the **61 Qwen-invalid review records** inside the admitted 1,736; invalid reviews are retained, not excluded questions.

**The two checks are separate:** expected-answer support assesses the author key against reviewer-only evidence; reasoning / lookup assesses what can be distinguished from the original question. Database annotation support is not proof of reasoning-based answerability.

**AI review, not expert adjudication.** Original keys, scores, and saved judgments are unchanged. Contradicted labels are review flags, not confirmed key errors. Agreement and “reasoning-supported by both” remain model judgments, not scientific ground truth. No forced consensus is assigned.
