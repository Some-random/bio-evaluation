# Published benchmark comparisons — 15 October 2026

The audit covers all 64 biological settings. Values below are published, rounded references; they are not additional local evaluations. Exact comparison requires the same cases, evidence, metric and aggregation. The JSON records sources, native requirements, uncertainty and missing artifacts.

The existing local LitQA2 result is **77/197 correct (39.1%)**, with **41.0% precision** and **95.4% coverage**, one run on reviewed public IDs. The original paper uses public+private questions and three-run means. Neither this subset nor an image/input adaptation establishes a full-paper win.

Material caveats:

- ProtST/BioT5+/NatureLM references include trained specialist encoders, supervised heads or task instruction tuning. Local sequence-text Qwen is a distinct training/representation baseline.
- Bio-posttrain methods specify propagated GO-F1, while one appendix caption calls it Fmax. This source inconsistency is recorded; no metric is silently substituted.
- STRIDE full-action Table 3 prints Unique 78/79 although success is 89/100. Its narrative and table agree on 78 unique outputs; the inconsistent denominator is retained as a source issue. Oracle fluorescence is a predictor result.
- PFArena, NatureLM temporal descriptions, antibody geometry and selected generation settings still need exact released artifacts/evaluators. Valid biological prediction tasks remain in scope when representations are essential.
- Protected PG-LLM and flagged biological requests remain held. This audit ran no inference and read no protected PG-LLM test rows.
- No universal scalar is invented for qualitative design/retrieval case studies. No mechanism/explanation claim follows from endpoint accuracy alone.
