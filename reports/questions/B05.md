## Question

Which model shows the lowest MSE when chi1 = 300?

## Answer choices

- **A.** OPLS4a
- **B.** OPLS3e
- **C.** Both OPLS4a and OPLS3e have the same lowest value for MSE when chi1 = 300
- **D.** Insufficient information to answer the question
- **E.** OPLS4
