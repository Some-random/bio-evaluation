**Reading the scores:** “—” means no reported result for that model. The matched GPT comparisons use 197 LitQA2 cases, 82 SuppQA cases and 2,773 localization cases, with the archived Qwen 4K baseline. Unsuccessful responses remain in the denominator. For VQA-RAD, SLAKE and PathVQA, the paired values are open-answer token recall / closed-answer accuracy.

**LLaVA-Med:** All 193 questions are scored with Qwen3.8-27B as both solver and declared local judge. The score is 100 × the mean candidate/reference rating ratio, not clinical accuracy. A lossless outer JSON-fence extraction is applied consistently to all judge replies; the earlier strict-parser run is preserved. The paper used GPT-4 judging, so its 50.2 result is not directly comparable.

**Molecular-function annotation:** Qwen scored all 3,416 released test95 sequences using a fixed 489-label, three-decimal confidence output. Native AP/Fmax formulas are retained. This zero-shot full-sequence text adaptation differs from the trained ProtST model and its PDB-modeled input subset.

**Enzyme Commission classification:** Qwen scored all 1,919 released test95 sequences using a fixed 538-label, three-decimal confidence output. The native AP/Fmax formulas are retained; this is a zero-shot full-sequence text adaptation, not reproduction of the trained ProtST model or the PDB-modeled input subset.

**†** Stability classification is calculated from protein stability predictions, without a separate generation run. **‡** GFP candidate generation reports automated evaluator acceptance, not experimental fluorescence. Paper results based on predicted properties likewise do not establish experimental success.

Years distinguish older datasets from later benchmark releases where both are shown. NatureLM dates identify the published evaluations; some original test sets are unavailable. DrugBAN was first described in 2022 and published in 2023.


PFArena scores use the released native formulas on the stated subsets; the two T1 and two T3 cohorts are not pooled. MutaPLM values are learned surrogate predictions, not experimental fitness. ProtST retrieval has no released relevance labels and was evaluated with the released ProtST model, not Qwen.

Conditional-generation proxies include one-residue strings and have no matched control. Heme-complex generation produced severe clashes in all five structures. These outcomes do not establish protein function or binding.
