# P36 — reviewed 59-case Qwen baseline

59/59 saved request/response pairs archived: 17 completed, 42 error responses. Incremental backup; subset scoring remains pending.

[Case index](trajectory_index.json) · [Trajectory SHA manifests](trajectory_batches) · [Latest metadata archive](latest_metadata.json) · [Frozen condition](frozen_config.json)

This is a partial zero-shot adaptation of the BioT5+ released paired-reference ROUGE condition: 59 input-reviewed cases from 5,876 source cases. It is not full P36 completion, paper normalized Smith-Waterman scoring or biological function validation. Original requests and responses include reasoning, usage, malformed output and truncation. Saved error responses are preserved immediately and counted separately. Ambiguous request-only dispatch records are archived only once generation is terminal.
